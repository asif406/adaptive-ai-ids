# adaptive-ai-ids
Adaptive AI IDS is a Python-based Intrusion Detection System designed to monitor web server logs in real time and identify potentially malicious activity. The system detects threats such as SQL injection attempts, brute-force login attacks, DoS-like behavior, scanning activity, honeypot access, and abnormal requests. It assigns adaptive threat scores based on detected behavior and risk factors, records security incidents in SQLite, performs automated IP blocking, and supports email and Telegram alerts. The project also provides security analytics and geographic information for detected incidents.
